Назначение

IWE Calendar — личный инструмент интеграции Google Calendar с системой личного управления IWE. Приложение предоставляется «как есть», без каких-либо гарантий.

Использование

Приложение предназначено только для личного использования владельца аккаунта. Авторизация выполняется через экран согласия Google; объём доступа описан в политике конфиденциальности.
